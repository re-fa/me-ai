# By-Me-AI

A collection of software projects created with the assistance of artificial intelligence and guided by human ideas, prompts, testing, and review.

This repository is a personal laboratory for exploring what can be built with AI-assisted software development.

## Projects

| Project | Description | Live Demo |
|---|---|---|
| [Chat](./chat) | A peer-to-peer chat application built with WebRTC. | [Open Chat](https://re-fa.github.io/me-ai/chat/) |

## About This Repository

Each project has its own directory and its own documentation. The root README provides a short overview of the repository and links to the available projects.

For detailed information about a specific project, open its directory and read its README file.

## Development Approach

The projects in this repository are developed through a combination of:

- Defining the idea and expected behavior.
- Writing detailed prompts and requirements.
- Reviewing the generated code.
- Testing the project in real usage scenarios.
- Debugging and improving the implementation.

Artificial intelligence may generate parts of the implementation, but the projects are directed, tested, and reviewed by me.
